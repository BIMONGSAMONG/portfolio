채팅 상담하기↗

카카오톡 채팅 상담

  • 채팅 상담은 월~금 09:00~18:00에 가능합니다. (토,일,공휴일 휴무)
  • 업무시간 외에 문의를 남겨주시면 익일 업무시간에 순차적으로 고객님께 답변을 드립니다.
  • 채팅 상담하기 버튼을 클릭하시면 고객님의 카카오톡으로 알림톡이 전송됩니다.
  • PC에서 신청하실 경우 고객님의 PC와 모바일에 모두 전송되며, 모바일에서 신청하실 경우 모바일(휴대폰)로 전송됩니다.
  • 카카오톡이 설치되지 않았을 경우, 카카오톡 설치를 부탁드립니다.
  • 카카오톡 채널 검색 ‘소니코리아고객센터’를 통해서도 카카오톡 채팅 상담이 가능하오니 채널 추가를 통해 추후 편리하게 이용해보세요
상담 예약하기↗

영상 상담

  • 영상 상담은 월~금 10:00~17:00에 가능합니다. (토,일,공휴일 휴무)
  • 영상 상담은 고객님의 제품을 고객님과 전문 상담원이 영상을 통해 실시간으로 서로 확인하며 상담하는 서비스입니다.
  • 영상 상담 예약하기 버튼을 클릭하신 후 원하시는 시간대로 신청해주시면 소니코리아 전문 기술 상담원이 고객님께 연락을 드릴 예정입니다.
  • 신청해주신 시간이 확정된 것은 아니며 전문 상담원과의 연락을 통해 최종 시간이 확정됩니다.
  • 영상 상담 예약을 위해서는 별도의 개인정보 활용 동의가 필요합니다. 고객님의 개인정보는 상담이 끝난 직후 삭제 됩니다
  • 영상 상담 예약 관련하여 변경/취소가 필요하신 경우 소니코리아 고객센터 1588-0911로 문의하시기 바랍니다.
챗봇 상담하기↗

챗봇 상담

  • 챗봇 상담은 상담사가 아닌 로봇이 고객님의 문의에 맞는 내용을 안내 드리고 있습니다.
  • 채팅 상담을 통한 상세 문의는 카카오톡 채팅 상담하기로 문의하시기 바랍니다.
